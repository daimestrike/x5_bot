# Релиз v1.2.0 — заметки

## Что нового

**ИИ-ответ по базе знаний (RAG).** Вопрос, написанный фразой, больше не упирается в «понимаю только меню»:
поиск находит фрагменты в карточках и загруженных документах, модель отвечает **только по ним** и ссылается
на карточки кодами `[A-07]` — коды становятся кнопками, под ответом привычные «Помогло / Не помогло».

- `app/llm.py` — клиент OpenAI-совместимого API на стандартной библиотеке (X5 CoPilot, vLLM, Ollama, LiteLLM, TGI):
  свой CA, системный прокси выключен, `<think>` у reasoning-моделей вырезается. **Новых зависимостей нет.**
- `app/rag.py` — BM25 с русским стеммингом; эмбеддинги необязательны (RRF, кэш в отдельном SQLite).
- `app/assistant.py` — связка поиска и модели; ответ без ссылок помечается как неподтверждённый.
- Вкладка **ИИ** на `/content/`: состояние, размер индекса, проверка связи с моделью.
- `scripts/mock_llm.py` — заглушка модели: конвейер проверяется без доступа к контуру.

По умолчанию `AI_ENABLED=false` — бот работает строго по меню и поиску, как в MVP. Сбой или таймаут модели
не ломает диалог. Запрос к модели выполняется вне транзакции SQLite и в пуле потоков.

**Обновление установки одной командой.** `update.sh` проверяет контрольную сумму, делает резервную копию,
заменяет код, доустанавливает зависимости и перезапускает службу; при ошибке откатывает код.
`.env`, `data/` и `content/` (карточки, слепки, очередь) не трогаются.

**Для сервера:** `deploy/rooms-bot.service` — готовый systemd-юнит. Раздел «Быстрые команды» в начале README.

## Требования

- **Ubuntu, 64-разрядный Python 3.10 или новее** (проверено на 3.10–3.13).
- Доступ к **внутреннему зеркалу PyPI** — это единственный способ поставить зависимости,
  если каталог `wheels/` пуст. Docker и docker compose не нужны.
- Версии в `requirements.txt` заданы диапазонами, чтобы зеркало могло отдать то, что у него есть.

## Установка на Ubuntu в контуре

```bash
sudo mkdir -p /opt/rooms-bot && sudo chown "$USER" /opt/rooms-bot
tar xzf ~/rooms-bot-1.2.0.tar.gz --strip-components=1 -C /opt/rooms-bot
cd /opt/rooms-bot
./setup.sh --index-url "https://ВНУТРЕННИЙ-PYPI/simple"
./start.sh
```

## Обновление работающей установки

```bash
cd /opt/rooms-bot
./update.sh ~/rooms-bot-1.2.0.tar.gz --index-url "https://ВНУТРЕННИЙ-PYPI/simple" --service rooms-bot
```

`.env`, журнал `data/` и содержание `content/` остаются от установки; при ошибке код откатывается
из `backups/`.

Если внутреннего зеркала нет, соберите набор пакетов на машине с доступом в сеть — на такой же ОС,
архитектуре и версии Python — и положите в `wheels/`, тогда работает `--offline`:

```bash
pip download -r requirements.txt -d wheels
```

Включить ИИ: в `.env` задать `AI_ENABLED=true`, `AI_URL` (вместе с `/v1`), `AI_MODEL`, перезапустить.

## Что в архиве

Код, содержание, тесты, systemd-юнит — 75 файлов. Каталог `wheels/` пуст: пакеты ставятся
из внутреннего зеркала PyPI либо собираются отдельно (см. выше). Не входят: секреты и `.env`, журнал `data/`,
слепки документов, очередь проверки, внутренние материалы в `.docx`.
Контрольная сумма — в `rooms-bot-1.2.0.tar.gz.sha256`.

125 тестов, `ruff` чистый. Архив проверен: распакован начисто, тесты проходят, бот запускается с ИИ,
обновление поверх установки сохраняет данные.
