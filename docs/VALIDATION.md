# Результаты проверки

Дата: 15 сентября 2026. Проверяется текущая поставка, а не исходная версия проекта.

- Python 3.12, отдельное виртуальное окружение; установлены точные версии прямых зависимостей из requirements.txt / requirements-dev.txt.
- `pytest`: **100 passed** (повторный прогон после автоматического сопоставления источников).
- `ruff check app scripts tests`: **All checks passed**.
- `pip check`: зависимости проверены на совместимость.
- `validate_content.py`: **35 карточек, 0 согласованных**; это исходные черновики. Production-валидация не считается пройденной.
- Проверка через браузер: вход в необязательный симулятор, приветствие, открытие меню с пятью разделами, постоянные «Меню»/«Поиск», компактный вид. Ранее проверены поиск «модем», карточка A-07 и причины отрицательной оценки. Это симулятор, не клиент Rooms.

Тесты покрывают сценарии S0–S8, доступность всех 35 карточек, ограничения поиска, чужие/просроченные кнопки, версии оценок, дедупликацию, срок хранения, приватность БД, авторизацию, отключённую в production консоль и ограничения тела запроса.

Для прямого BotX дополнительно проверены разбор команд и кнопок, HMAC token exchange, обновление токена при HTTP 401, проверка JWT issuer/audience/времени, отказ ложного успеха при HTTP 202 или `status: error`, атомарная очередь, возобновление после перезапуска, удаление истёкших ответов и зашифрованная маршрутизация. Сетевой транспорт проверен `httpx.MockTransport`, без обращений к X5.

Один DeprecationWarning связан с используемым Starlette TestClient и новым AnyIO. Он не скрыт. Это предупреждение тестового инструмента, тесты завершаются успешно.

Автоматические связи источников дополнительно проверены 13 сценариями: заголовки и строки таблиц Word,
формы русских слов, перенос и изменение абзаца, сохранение связей при повторном создании приложения,
неизменённый текст при разных ZIP-метаданных, повторы абзацев, удаление, изменение контекста,
неоднозначные совпадения, посторонняя тема, старый формат слепка и изменение определения карточки.
Полный прогон: `100 passed`, Ruff и `git diff --check` без ошибок. Этот прогон выполнен локальным Python 3.9;
предыдущая проверка установки на Python 3.12 не заменяет проверку на целевой машине.
Файл «MVP бота Rooms.docx» также прочитан новым парсером: 106 фрагментов, 13 заголовков, 46 строк таблиц.
Это проверка извлечения, а не измерение точности сопоставления на размеченной выборке.

## Что не проверено

- Фактический доступ к X5 Rooms, Keycloak-шлюзу, регистрация Bot ID, доставка на телефон, входящие callback и поведение кнопок в установленной версии.
- Сборка Docker и выполнение GitLab CI: Docker/runner в этой среде отсутствуют. Запуск без Docker проверяется тестами установщика и стартового скрипта; фактическая установка на целевой Linux/Windows машине требует внутренний PyPI либо wheelhouse для её ОС, архитектуры и Python 3.12.
- Содержательное согласование карточек, рабочие ссылки и контакты помощи.
- Нагрузочная эксплуатация, несколько реплик, отказ диска и инфраструктурное восстановление.

Следующий интеграционный шаг — получить контракт, перечисленный в ROOMS-INTEGRATION.md, дополнить шлюзовую авторизацию и пройти сценарии на тестовом боте в контуре. До этого обозначать проект как уже работающий в X5 нельзя.
