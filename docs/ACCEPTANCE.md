# Сверка с исходным MVP и чек-листами

Основание: подтверждённые заказчиком 17 сентября 2026 года файлы «MVP бота Rooms.docx» и «Чек-листы_бота_Rooms.xlsx». В Excel четыре листа: «Экраны и кнопки», «Диалог сценарии», «Реестр материалов», «Правила ответов». Документ упоминает лист приёмки, которого в переданном файле нет. Файлы с пометками v9/v11 в имени не используются. Точные имена и контрольные суммы зафиксированы в [SOURCE-BASELINE.md](SOURCE-BASELINE.md).

| Требование | Реализация / проверка | Статус |
|---|---|---|
| S0, приветствие один раз за сеанс | Engine, тесты повторного открытия и таймаута | Выполнено |
| S1, пять разделов + поиск + помощь | Пять разделов A–E, буквальный поиск и маршрут помощи | Выполнено |
| S2, максимум 8 тем и ≤3 кликов до карточки | Пагинация A на две страницы; проверены все 35 карточек | Выполнено |
| S3, короткий ответ и навигация | Заголовок, шаги, ссылка, оценка, темы, меню | Логика выполнена; реальные ссылки ожидаются |
| S4 / S4a, причины «Не помогло» | Три точные причины, ссылка на инструкцию и маршрут помощи | Выполнено |
| S5, буквальный поиск, ≤5 результатов | Подстрока в названии/синонимах/тексте; длинный вопрос отклоняется | Выполнено |
| S6, три вида помощи | ПИ / техника / организация; выбранный тип записывается в журнал | Логика выполнена; контакты ожидаются |
| S7, произвольный текст и вложения | Не интерпретируются через ИИ, не скачиваются, возврат к меню | Выполнено |
| S8, недоступный материал | Резервная инструкция и совет обратиться к ревизору | Логика выполнена; резервная ссылка ожидается |
| 35 карточек A10/B8/C6/D8/E3 | Импорт исходного содержания, проверки ID и числа карточек | Выполнено |
| До 600 знаков и 6 шагов, ≥3 синонима | Автоматическая валидация | Выполнено |
| Версия/дата/владелец/согласование | YAML, история Git, production-валидация | Владельцы/согласование ожидаются |
| Журнал без ПДн и содержания ПИ | HMAC сеансов; редактирование данных не требуется, исходный текст не хранится | Выполнено для приложения |
| Повтор оценки не увеличивает метрику | Привязка к показу/версии/сеансу, первая оценка фиксируется | Выполнено |
| Никаких самостоятельных этапов и напоминаний | Только реакция на запрос; повтор доставки не создаёт новый сценарий | Выполнено |
| Работа на телефоне без прерывания записи ТСД | Штатный чат Rooms, короткие сообщения | Требуется проверка на устройстве X5 |
| Работа внутри корпоративного Rooms | Прямой BotX v4; обнаружена дополнительная авторизация X5 | Шлюз X5 и контурная проверка не завершены |
| GitLab и закрытый контур | CI, offline Docker или запуск из ZIP без Docker, секреты вне Git | Установщик поддерживает внутренний PyPI и offline wheelhouse; адреса/пакеты предоставляет инфраструктура |

В противоречии Excel о сохранении свободных фраз и MVP о запрете ПДн/содержания ПИ выбран запрет на хранение текста. Статистика отражает число промахов поиска, а не список произвольных пользовательских запросов.

Карточки остаются черновиками. Производственный запуск до их согласования намеренно отклоняется. Зелёные программные тесты не заменяют содержательную приёмку и проверку транспорта X5.
